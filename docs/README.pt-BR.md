# Documentação

[English](README.md) | **Português**

A documentação segue o modelo [Diátaxis](https://diataxis.fr/): cada parte responde a uma necessidade diferente de quem lê.

| Parte | Para quando você quer... | Situação |
| --- | --- | --- |
| [**Tutorial**](tutorial.pt-BR.md) | aprender fazendo: seu primeiro livro, do zero ao site | pronto |
| [**Perguntas frequentes**](faq.pt-BR.md) | ter uma resposta rápida: planos, custo, privacidade, idiomas, imagens | pronta |
| [**Integrações**](integrations/README.pt-BR.md) | conectar ou instalar algo à parte: GitHub, Notion, Google Drive, Docling, GitHub Pages, WSL 2 | pronta |
| **Guias** | fazer uma tarefa: criar a sua biblioteca, publicar um livro pronto, continuar um livro | a escrever |
| [**Referência**](reference.pt-BR.md) | consultar um detalhe: estrutura de pastas, `book.yaml`, `library.yaml` | pronta (para os scripts, rode qualquer um com `--help`) |
| **Explicação** | entender o porquê: como a skill funciona, a didática, a economia de tokens | a escrever |
| [**Testes**](testing.pt-BR.md) | mudar a skill ou os scripts: como os testes funcionam e como acrescentar um | pronta |
| [**Changelog**](../CHANGELOG.md) | ver o que mudou em cada versão (em inglês) | sempre atualizado |
| [**Decisões**](decisions/README.pt-BR.md) | saber por que o projeto é como é (registros de decisão) | pronta |

O plano de trabalho até a 1.0, com o histórico de cada decisão, está em [`plano/`](../plano/).
