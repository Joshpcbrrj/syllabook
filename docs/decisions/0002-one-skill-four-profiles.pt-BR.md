# 2. Uma skill com quatro perfis de área

[English](0002-one-skill-four-profiles.md) | **Português**

**Situação:** aceita · **Origem:** `plano/PLANO.md §2, §6`

## Contexto

Programação, idiomas, música e história se ensinam de jeitos muito diferentes, mas a maior parte do trabalho (ementa, pesquisa, checagens, publicação) é a mesma.

## Decisão

Uma skill só, com quatro perfis de didática lidos quando o tema pede: `stem`, `languages`, `skills` e `knowledge` (no máximo dois por livro).

## Consequências

Uma instalação serve para qualquer tema, e cada livro lê só o seu perfil. Um tema que não se encaixa em nenhum ganha um método próprio, explicado no parecer.
