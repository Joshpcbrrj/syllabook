# 9. CC BY-SA 4.0 for the content, MIT for the code

**English** | [Português](0009-licenses.pt-BR.md)

**Status:** accepted · **Source:** `plano/PLANO.md §2, §15`

## Context

People should be free to study, share and adapt the books, and to reuse the code of the examples in their own projects.

## Decision

The library template uses CC BY-SA 4.0 for the text and MIT for the code; each person may choose other licenses for their own library in `library.yaml`. This repository uses the same pair: its documentation is CC BY-SA 4.0 and the skill and scripts are MIT.

## Consequences

Books made with the template can be shared and adapted with credit. Third-party passages stay as short quotations with their link.
