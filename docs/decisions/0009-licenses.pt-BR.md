# 9. CC BY-SA 4.0 para o conteúdo, MIT para o código

[English](0009-licenses.md) | **Português**

**Situação:** aceita · **Origem:** `plano/PLANO.md §2, §15`

## Contexto

As pessoas devem poder estudar, compartilhar e adaptar os livros, e reaproveitar o código dos exemplos nos seus projetos.

## Decisão

O modelo de biblioteca usa CC BY-SA 4.0 para o texto e MIT para o código; cada pessoa pode escolher outras licenças para a sua biblioteca no `library.yaml`. Este repositório usa o mesmo par: a documentação é CC BY-SA 4.0, e a skill e os scripts são MIT.

## Consequências

Os livros feitos com o modelo podem ser compartilhados e adaptados com crédito. Trechos de terceiros ficam como citações curtas com link.
